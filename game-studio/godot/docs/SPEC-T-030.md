## Goals
1. **Local profile** (`scripts/meta/profile.gd`, saved as JSON under `user://profile.json`, versioned, tolerant of missing/corrupt file): display name (player-chosen, default "Analyst"), created date, reputation points, current streak, best streak, last finished day (calendar date), leave days remaining, achievements, history of finished runs/days. A clock interface (`Clock.today()`) so tests inject dates; never read the real date directly in logic.
2. **Run/day log**: after each finished game day, append a compact record: day id (date or run seed + day index), seed, the submitted inputs (forecast, confidence, evidence uids, actions, submit minutes), the resulting public score parts (accuracy, trust delta, timing tag, pay, bonus), rank. This **input log** format is the future server-verification payload; document it in `docs/INPUT-LOG-FORMAT.md`. Only public data; hidden truth is stored only after the day's review (as the game already reveals it).
3. **Daily Shift mode**: new title-screen option next to Play: "Daily Shift" uses a seed derived from the calendar date (same for everyone on that date in the future online mode), 1 day only (or the normal 10-day run starting from that seed; choose the simpler one and document). The normal "Play" mode stays as is.
4. **Wall of Fame scene** (new scene reachable from the title screen and shown as a framed wall in the Reception room if it can be done without touching the office art beyond one prop): framed plaques with pixel avatar, display name, title and month for **Employee of the Month** winners, plus all-time awards (longest streak, highest rank reached, best single day, Most Honest Analyst, Never Late). With no online players yet, the local profile's own runs are the candidates; show locked/empty plaques for awards not yet earned. Monthly winner: computed at month rollover from the best N days (N=10, configurable) of the local history by score, ties by accuracy; stored permanently.
5. **Achievements** (data in `data/meta.json`, English): e.g. First Report, Perfect Day, Verified Before Reporting, Survived 10 Days, Promoted to Senior, Zero Late Week, 7-Day Streak. Toast popup in the same style as the money popups when earned; list inside the Wall of Fame scene.
6. **Attendance ladder (simulated, offline)**: at game start, compare today with `last finished day`. Missed days (excluding covered leave days) escalate per `docs/DESIGN-online.md` section 5: reminder (1), warning (2), fine (3), formal warning (5), termination notice (7), "rehired as Intern" on 8+ (history kept, never deletes the profile). Effects only change **local meta values**: reputation points (reduced, floor 0) and a small cap-limited **fine applied to the next run's starting wallet**. Config in `data/meta.json` (percentages, caps, leave allowance per month default 3). A **Request leave** screen (pick a valid reason from a humorous list, days 1-3, only for future or today) marks days covered. A "welcome back" bonus softens the return. Streak freeze item earned at 7-day streak.
7. **"While you were away" screen**: when the ladder triggers, show an in-game HR/Boss letter (cozy paper style, original humorous English lines, at least 6 lines per step, tone: scolding with humor, never about real-life obligations or shaming) with the penalty applied and a "Request leave next time" hint. Lines go in `data/meta.json`. These are **in-game messages only**; document in the handoff how a future notification channel would reuse the same lines (do not implement notifications).
8. **Settings**: a small settings screen from the title: display name, reset profile (confirm), toggle "attendance warnings" (so players can switch off the pressure mechanic), quiet-hours placeholder for the future (stored, unused). Default: attendance mechanic ON, with a first-run explanation screen.
9. **Interfaces for online later**: `DaySource` (local implementation: seed from date or run), `ScoreSink` (local implementation writes profile/log). The game flow calls these instead of reading/writing directly; no behavior change.
