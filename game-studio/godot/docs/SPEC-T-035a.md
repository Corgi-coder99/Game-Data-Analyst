# Spec T-035a: Case catalog and Analyst Handbook content (docs + data, no code)

Owner: Claude subagent. Reviewer: Claude. Base `v2`. Worktree `D:\Dev\ai-company-t035a`, branch `codex/T-035a`. No Godot, no game code. Read `docs/DESIGN-data-core.md` first (sections 1, 3, 7).

## Goal
Author the teaching content for the data-analyst core so that code tasks (T-034, T-035) can plug it in: a catalog of realistic analysis cases and in-game Handbook cards, in English, accurate to standard analytics practice, with fictional data only.

## Deliver
1. `docs/CASE-CATALOG.md` (human-readable) and `data/cases.json` (machine-readable, valid JSON, ids stable). At least **24 cases**, each with: `id`, `title`, `skill` (data_cleaning, charts, statistics, causality, communication), `method` (existing project skills: data-quality-audit, programmatic-eda, root-cause-investigation, funnel-analysis, cohort-analysis, segmentation-analysis, ab-test-analysis, time-series-analysis, visualization-builder, analysis-planning), `dataset_type` (sales_export, market_prices, web_funnel, loan_book, ab_test_log, support_tickets, competitor_scrape), `boss_question` (templates compatible with the existing question style in `data/questions.json`; forecast direction up/down/flat where applicable), `trap` (the real-world pitfall), `dirt` (list of defect types from design section 3), `reference_steps` (the correct cleaning/analysis steps in plain words), `truth_statement_templates` (what the correct findings look like), `wrong_paths` (typical wrong answers and why), `difficulty` (1-5), `unlock_day`, `handbook_card_ids`. Cover these traps at least once each: duplicates, missing-as-zero, mixed units/currency, date format/timezone, category typos, entry-error outlier vs real spike, seasonality vs trend, Simpson's paradox, small sample noise, correlation vs causation, base rate, survivorship bias, cherry-picking, misleading axis, double counting, late-arriving data, A/B significance (p-value, sample size, peeking), funnel drop-off, cohort retention, segmentation, root-cause drill-down, regression to the mean, join mismatch, test accounts.
2. `data/handbook.json` and `docs/HANDBOOK.md`: **Handbook cards** (one per concept, at least 30): `id`, `title`, `skill`, `what` (2-3 sentences), `when_to_use`, `common_mistakes` (2-4 bullets), `example` (tiny fictional example with numbers), `how_in_game` (which Sheet operation or chart to use), `see_also`. Short, plain language for beginners (a new player knows nothing), accurate (no invented statistics; explain p-values and significance carefully; no investment advice).
3. `data/coaching.json`: mentor/boss **coaching lines** for the review step: for each trap, a praise line (player fixed it), a miss line (player missed it), a wrong-fix line, each 2-3 variants, original, friendly with light humor, no shaming. Include the characters' voices: Ms. Hanh (boss, direct), Khoi (colleague, jokey), a new mentor "Dr. Linh" (calm teacher).
4. `docs/TUTORIAL-CASES.md`: a scripted 5-case onboarding ladder (day 1 to 5) with exact learning goals, the tiny datasets (as CSV text, 10-30 rows, fictional) including the defects, the expected steps and the expected findings, so T-035 can implement a guided tutorial.
5. A validator script `tools/validate_content.py` (run with `python -X utf8 -I`): checks JSON validity, unique ids, cross-references (handbook ids, trap coverage list above, dataset types, difficulty range), English-only (no Vietnamese diacritics), and minimum counts. Output PASS/FAIL lines.

## Rules
- All data and names fictional; no real companies or people; no copyrighted text. Statistical statements must be correct: double-check definitions (median vs mean, IQR rule, Simpson's paradox example with consistent numbers, A/B test sample size notes).
- Do not edit game code, existing `data/*.json` (add new files only), CLAUDE.md, or other docs besides the listed ones. No network/push/merge.

## Guard rules
Same failing validation after 2 fix attempts: stop and report. About 60 minutes. Commit small steps. Handoff in `docs/HANDOFF-T-035a.md` with validator output and any content you are unsure is statistically accurate.
