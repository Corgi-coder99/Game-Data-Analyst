## Goal
Make the game teach. Players learn real analysis methods by meeting cases, getting hints on demand, and receiving coaching after each day, with visible skill progress.

## Guard rules
Same failing test after 2 fix attempts: stop and report root cause. Spec conflict: stop and report, never lower targets silently. About 150 minutes, milestone commits. Godot commands with timeout <= 5 min, one Godot process at a time. No network/push/merge. Handoff in `game-studio/godot/docs/HANDOFF-T-035.md` with real counts, no placeholders.

## Build
1. **Case mapping**: each generated file (dataset type + dirt types + difficulty + day) maps to a case in `data/cases.json` (code in `scripts/learn/case_map.gd`; fallback to the closest case by dataset type and trap). The day's case id is public (title and skill only); its trap, reference steps and wrong paths stay hidden until review.
2. **Handbook app** (new desktop icon "Handbook"): lists the 49 cards from `data/handbook.json` grouped by skill, searchable by title, with a detail view (what, when to use, common mistakes, example, how in game, see also with links). Cards **unlock** when the player meets the case or uses the related operation; locked cards show title only with a lock icon and "Meet this case to unlock". Opening is free (no Energy, no clock) but takes no focus away from deadlines (it is a reference).
3. **Hint button** in Sheet/Charts/Mail: costs 1 analysis Energy (config `learn.hint_energy`), gives a **method card** relevant to today's case (not the answer, not the reference steps), at most once per case per level (3 levels: name the problem type, name the method, name the Sheet operation family). Hint use is recorded (affects coaching lines and a small "Hint used" tag in the review, not the score).
4. **Coaching in the review step "Your analysis"** (extends T-034): for each hidden defect/trap in the day's files, show the mentor line from `data/coaching.json` by outcome (praise if fixed, miss if missed, wrong_fix if wrongly changed), voice rotating among Ms. Hanh, Khoi, Dr. Linh (new mentor sprite in the cozy style, original, palette v4, same size as other staff; she appears in the review and the Handbook), and the "what the data actually said" explanation with the reference steps in plain words, a link to the Handbook card (unlocks it). Chart quality flags get their teaching text here too.
5. **Guided tutorial mode**: a first-run choice "Tutorial days 1-5 (recommended)" vs "Skip tutorial" (setting remembered in the profile). In tutorial mode days 1 to 5 use the five tiny hand-built datasets and scripted steps from `docs/TUTORIAL-CASES.md` (duplicates and spellings, extra-zero vs real move, funnel partial last day, tiny A/B test, Simpson's paradox) with coach marks that react to real actions, an "I'm stuck" button that shows the next step, and a celebration popup when a case is solved. The world scenario and questions still run normally; the scripted files replace the generated files only in tutorial mode and are leak-safe (public data only; expected findings hidden until review). Use the same IQR method (median of halves) and Fisher exact test as the tutorial doc, or fix the doc and say so.
6. **Skill progress**: five skills (Data cleaning, Charts, Statistics, Causality, Communication) with level 1-5 and XP, stored in the local profile (T-030): XP from correct fixes, good charts, correct findings, calibrated confidence; shown on the Wall of Fame and in the review as small bars with level-up toasts (existing toast style). Unlock handbook cards and achievements ("First Clean", "Sharp Eye" for catching an outlier, "No Cherry Picking", "Honest Axis", etc., add 8 achievements in `data/meta.json`).
7. **Difficulty ramp**: after the tutorial, difficulty follows the profile's skill levels and the day (config `learn.ramp`), never changing world answers or balance; document how it chooses dirt count and file size.

## Constraints

- All new strings in `strings_v2.json` (`learn` section) or the content JSONs.
