# Contributing

Thanks for your interest. This project is maintained by a small team; please keep changes focused and small.

## Getting started

1. Install Godot 4.7 and open `game-studio/godot` (see `README.md`).
2. Run the tests listed in the README before and after your change.

## Workflow

- Branch from the main development branch: `feature/<short-name>`, `fix/<short-name>` or `docs/<short-name>`.
- Keep commits small and use Conventional Commits (see `docs/COMMIT-CONVENTIONS.md`).
- Open a pull request that explains what changed and how you tested it.

## Code and data guidelines

- GDScript, Godot 4. Code, identifiers and comments are in English.
- Keep game data (numbers, text, cards, events, news) in `data/*.json`, not hard-coded in scripts.
- Keep the simulation core in `scripts/sim/` free of node dependencies so it can run headless.
- New or changed gameplay logic needs a test; run the balance simulation if you touch the economy.
- Art must be generated by code or be your own work, use only the locked palette in `shared/style-bible/`, and must not use copyrighted characters, logos or music.
- Everything in the game is fictional. Do not add real companies, people, brands or real market data.

## Documentation

Write repository documentation in English. Do not commit secrets, API keys or personal data.

## Licensing

The project license is still to be decided by the owner. By contributing you agree your contribution may be released under the license the owner later chooses.
